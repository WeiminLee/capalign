# ACL Method 主图 notes（中文稿）

**Files**
- `cap-align-acl-main-zh.drawio` — 可编辑源（draw.io）
- `cap-align-acl-main-zh.png` — 嵌入 XML 的预览 PNG
- `cap-align-acl-main-zh.pdf` — 矢量 PDF（投稿用）

**Style:** drawio-skill built-in `colorblind-safe`（Okabe–Ito）；Skill-V 观感：软色块分区 + 栏间粗灰箭头；无 ★ / 「核心贡献」标语。

**Layout (LTR, 中栏最宽)**
| 区 | 角色 |
|---|---|
| (a) 蓝 | 双编码 $W_{paper}\parallel W_{repo}$ → Id 合并 $u$ → $\lambda(u)$ 分区表 |
| (b) 琥珀焦点 | Obl/Ent → 同一 $\lambda$ 投影分叉 → qha / band 两卡 → 不相交 ⇒ 单面合同错 → 示意表 |
| (c) 绿 | $\lambda\to I$、安装/拒绝、$K_H$、FI / Miss / $t_v$、fail-before→destroy |

**贡献如何“画出来”（不贴标签）**
中栏把「同一 $\lambda$」收成一个投影枢纽，再**视觉分叉**成论文面缺口 `Obl∖Ent`（qha）与仓库面缺口 `Ent∖Obl`（band）；下方芯片直接标出 wrap-repo 的 FI+Miss 与仅论文的 $t_v{=}0$。读者不读「这是贡献」也能从分叉事件读出：单面策略合同错误，必须类型化引入（可拒绝）。

**Caption 草案（可改）**
双编码按产物 Id 合成槽位并得到 $\lambda$；同一 $\lambda$ 在论文面/仓库面上的宿主缺口可不相交（示意 qha / band）。算子 $I$ 按 $\lambda$ 安装或拒绝并写入 $K_H$；对照 wrap-repo / 仅论文在 FI、Miss、$t_v$ 上失败。示意表非经验数。
